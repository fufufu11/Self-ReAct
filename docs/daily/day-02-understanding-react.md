# Day 2：理解 ReAct

## 今天理解了什么

今天从整体上理解了 ReAct 的框架。ReAct 可以理解为 Reasoning and Acting，即“推理与行动”。它的核心是“思考 -> 行动 -> 观察 -> 再思考”的闭环：模型以当前任务和上一轮得到的 Observation（观察）作为上下文进行推理，再决定下一步要执行的行动。

行动执行后，工具或环境会返回新的观察结果。模型再基于这些结果进行新的推理，选择继续行动，或者给出最终回答。通过这种方式，模型能够在完成任务的过程中一边思考，一边与外部环境交互。
